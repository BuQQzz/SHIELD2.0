# Component Library

This directory contains reusable UI components built with shadcn/ui and Lucide icons.

## Structure

- `ui/` - Base UI components from shadcn/ui
- Feature-specific components will be organized in dedicated subdirectories

## Guidelines

- Keep components under 300 lines
- Use TypeScript for type safety
- Follow shadcn/ui patterns
- Use Lucide icons for all iconography
